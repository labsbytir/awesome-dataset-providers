# Proposal

## Why

Create a community awesome list cataloging dataset providers and datasets, starting from data.gov organizations and 500 Harvard Dataverse datasets, so researchers can discover sources, licenses, formats, and citation metadata.

## What Changes

- Add README awesome list with provider and dataset schema fields.
- Add scraper scripts for data.gov organizations and Harvard Dataverse datasets.
- Add JSON data outputs for providers and datasets.
